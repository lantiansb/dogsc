# DogSC Windows 0.2.18 —— 与 Mac 原版操作对齐

本版以 Mac 原版 DogSC 的操作逻辑为准，逐项对齐录制、时间线、画布、检查器、导出和渲染行为（快捷键中的 ⌘ 对应 Ctrl，⌥ 对应 Alt）。已有 `.frametrail` 工程可以直接打开；旧工程里的缩放、摄像头与光标参数保持原样，只有新建内容使用新的默认值。

## 录制

- 选择来源时先出现选择层：显示器、窗口、区域都需要确认后才开始录制，区域可以在开录前调整大小。
- 录制设置（来源、麦克风、摄像头、系统声音、保存目录、帧率、分辨率、录制模式）会被记住，下次启动沿用。
- 录制条可以拖动并记住位置，计时与实际录制同步，录制中的提示改为右上角通知，不再写进看不到的状态栏。
- 录制结束后弹出完成卡片，可以选择进入编辑、保存或丢弃，不再强行切换到编辑器。
- 开录时麦克风或摄像头启动失败会整体回滚，不再生成空项目或重复报错。
- 录制中某一条独立轨出错不再终止整段录制；被中断的录制会在保存/录制面板里提供一键恢复。
- 录制标记快捷键只在录制中注册；设置里新增“录制结束后自动生成缩放”开关，“录制时排除编辑器窗口”默认关闭，与 Mac 一致。
- 新生成的摄像头轨道使用 Mac 默认外观：方形、贴边、大小 0.29、白色边框、镜像，缩放时缩小到 0.7。

## 时间线

- 点击空白处取消选择，S / Q / W / Delete 只作用于明确选中的对象；连按 Delete 不再误删相邻片段。
- 在效果轨空白处单击创建默认长度的片段，拖动创建指定区间；缩放、屏幕 3D、摄像运动、贴图、柔化轨道常驻显示。
- 同一效果轨内的片段互不重叠：创建、拖动、粘贴、检查器修改都会贴合邻近片段，放不下时提示“此处没有足够空间”。
- 主片段重排落点正确，边缘裁剪有实时预览，相邻片段之间有约束，剪切缝可合并或还原被剪掉的素材。
- Alt+点击主片段在点击处直接切分，Alt 悬停显示剪刀引导；Ctrl 拖动右端可自由变速。
- 吸附规则、引导线、拖到视口边缘自动滚动与 Mac 一致；Esc 可以中止正在进行的拖动或创建。
- 播放头会自动滚入视野；点击片段只选中、不移动播放头；帧步进对齐帧网格，Shift+←/→ 一次 5 帧。
- 录制标记可以在标尺上点击跳转、右键删除；删除主片段或用 Q / W 裁掉前后段时，落在被删范围内的标记会移到剪点，不再丢失。
- 新增 Ctrl+Shift+Z 重做、Alt+X 导出选中主片段范围、F1 快捷键速查；焦点在滑杆、下拉框上时方向键归控件，其余快捷键仍然可用。

## 画布与播放

- 在画布上点击选中或取消选中对象，拖动时实时预览并显示吸附参考线与读数；轻点选择框不再产生空的撤销步骤。
- 新增画布裁切编辑器，进入裁切后 Esc 取消、Enter 完成，期间撤销和重做被禁用。
- 贴图与柔化区等比缩放并带旋转手柄；选中后在画布上出现快捷控件；摄像头选择框按真实形状绘制。
- 选择框只在对象于播放头处生效时出现，播放中自动隐藏，窗口缩放或拖动分隔条后重新对齐。
- 画布比例新增“自适应”和横竖切换；播放到结尾后再次播放从头开始，按住空格不再反复开关播放。
- 拖动中松开鼠标、窗口失去焦点或按 Esc 都会安全结束手势；Esc 先取消正在进行的画布手势，再轮到时间线和检查器。

## 检查器

- 滑杆、位置板、颜色和数值框在拖动与键盘步进时实时预览，松手后只产生一个带动作名的撤销步骤；Esc 恢复原值。
- 数值以百分比、倍数、秒等单位显示；非法颜色或数值只标红提示，不再弹出错误对话框。
- 面板头部显示作用范围（所选片段或全片），选中时间线片段时自动切换到对应面板，并记住各面板的滚动位置。
- 缩放面板新增焦点位置缩略图拖动、自动跟随与手动定位切换、应用倍率到全部、删除按钮；聚焦虚化的量程和形状限制与 Mac 一致。
- “启用聚焦”按 Mac 默认：屏幕 3D 使用线性清晰带，缩放使用径向焦点。
- 光标面板新增“无平滑”（原始轨迹）；平滑模式下可在“自定义手感”里调整弹簧质量、刚度、阻尼（默认 2.8 / 450 / 66），并可一键恢复默认。
- 切换点击效果时，若点击持续时间没有手动改过，会自动采用该效果的 Mac 默认时长（涟漪 0.36、柔光 0.32、脉冲 0.38、迸发 0.22）。
- 场景预设只应用样式并标记“已修改”；贴图、柔化、摄像运动等面板补上删除按钮。

## 工程与导出

- 撤销和重做显示动作名（如“已撤销：移动运镜”），没有变化的操作不再留下撤销步骤，重命名项目也进入撤销历史。
- 项目菜单与设置对话框补齐 Ctrl+O、Ctrl+E、Ctrl+, 等快捷键入口；设置项即时生效，外观支持跟随系统、浅色、深色（默认深色）。
- 导出默认使用源分辨率与 60 fps，并记住上次的选择；文件名带 `-60fps`、`-音频`、`-选区` 等后缀，重名时自动追加 `-2`，不再询问覆盖。
- 导出完成后窗口可再次导出，可以在资源管理器中定位文件；导出过程中关闭窗口需确认。
- 窗口位置、尺寸和最大化状态会被记住；错误与提示统一改为右上角自动消失的通知。
- 最近项目显示项目标题；删除项目会清空界面残留并移出最近列表；打开其他项目前先保存并检查是否有导出或录制在进行。

## 画面与动画

- 缩放改为 Mac 的整卡放大模型：画面卡片整体放大并可移出画布边缘，旧的“卡片内裁切”方式不再使用；手动缩放相邻交接按构图视口过渡。
- 屏幕 3D 的位置与枢轴语义与 Mac 一致；新建屏幕 3D 为 1.2 倍居中的平面姿态，进入与回落各 0.7 秒。
- 新建缩放默认 1.6 倍、过渡 0.7 秒、弹簧缓动，焦点取播放头处的鼠标位置（没有鼠标数据时居中）；倍率仍取你选择的倍率。
- 打码与贴图使用 Mac 默认：强度、圆角、硬切过渡；新贴图宽度 0.38 居中，同时间已有贴图时自动避让；摄像运动目标为当前摄像头放大 1.25 倍。
- 变速片段上的过渡跟随输出时钟，不再被压成闪切；删除或清除缩放后不会再自动“复活”。
- 带画布裁切时，画面按裁切后的比例适配画布；新建项目默认使用深色网格背景、Mac 的内边距、圆角与阴影；指针弹簧、点击时长等光标默认值与 Mac 一致。

## 已知限制

本版尚未对齐的 Mac 功能：

- 界面语言切换（目前仅简体中文）。
- 麦克风电平显示与摄像头悬浮预览。
- 线性聚焦虚化的画布手柄（目前只能在检查器里调整）。
- 时间线悬停预览（skimming）。
- 缩略概览条（总览条）。
- 效果片段随主片段拆分、裁剪、删除时的完整波纹移动与相位续接。
- 摄像头布局预设。
